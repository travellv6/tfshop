## 1. 项目概述

### 1.1 定位

TFShop 是一个面向全球玩具采购商的中国玩具工厂直供 B2B 电商平台。平台将中国玩具工厂的产品转化为全球可发现、可营销、可询价、可成交的商品资产。

**目标客户群体**：小B + 中B 买家（非直接面向普通消费者）。

### 1.2 核心差异化

| 差异化方向 | 说明 |
|-----------|------|
| 工厂源头直供 + 价格透明 | 砍掉中间环节，所有商品标注真实出厂价 |
| 小B 友好（低 MOQ + 快速发货） | 主打低起订量、小批发、现货直发，降低跨境卖家的试错成本 |

### 1.3 平台角色

**全流程交易平台**——提供从产品发现、询价、下单、支付到物流的完整链路服务，通过交易佣金盈利。

### 1.4 商业模式

**平台自营模式**——所有商品由平台团队统一上架管理、定价、发货。工厂是供货方，没有独立后台。每个产品归属某个具体工厂，前台展示工厂信息。

## 2. 目标用户

### 2.1 买家类型（4 类）

| 角色 | 描述 | 典型特征 |
|------|------|---------|
| 跨境卖家（Amazon/Shopee 卖家） | 小批量采购，关注价格、物流时效、产品认证 | 几十到几百件起订 |
| 区域批发商 / 分销商 | 大批量采购，需要专属价格、账期支持 | 千件起订，关注独家代理权 |
| 品牌商（OEM/ODM 需求） | 需要定制化生产，关注工厂产能、打样能力 | 走询价 + 报价流程 |
| 内容创作者 / KOL | 选品推荐、样品申请 | 采购量小，偏向营销合作 |

### 2.2 买家等级体系

| 等级 | 条件 | 权益 |
|------|------|------|
| Bronze（铜牌） | 新注册买家 | 标准价格、标准 MOQ |
| Silver（银牌） | 累计采购 $5,000+ | 95 折、可申请样品 |
| Gold（金牌） | 累计采购 $20,000+ | 9 折 + 专属价格、优先发货 |
| Platinum（铂金） | 累计采购 $100,000+ | 85 折 + 账期、专属客户经理 |

## 4. 系统架构

### 4.1 架构概览

采用 **Medusa 深度定制** 方案：充分利用 Medusa 2.0 现有模块，在此基础上通过自定义模块扩展 B2B 特有能力。

```
┌─────────────────────────────────────────────────────┐
│                  前台层 (Next.js + next-intl)         │
│  商品目录 | 询价中心 | 交易流程 | 买家中心 | 工厂展示   │
├─────────────────────────────────────────────────────┤
│                  API 层 (Medusa HTTP Routes)          │
│       Store API      |     Admin API     |  Webhook  │
├─────────────────────────────────────────────────────┤
│              业务逻辑层 (Workflows + Modules)          │
│  ┌───────────────────────┐ ┌─────────────────────┐  │
│  │ Medusa 原生模块        │ │ 自定义模块           │  │
│  │ Product · Cart · Order│ │ RFQ（询价管理）      │  │
│  │ Payment · Fulfillment │ │ Tiered Pricing      │  │
│  │ Customer · Inventory  │ │ Buyer Tier（买家等级）│  │
│  │ Pricing · Region      │ │ Factory（工厂）      │  │
│  └───────────────────────┘ │ MOQ Tag（起订量标签） │  │
│                            └─────────────────────┘  │
├─────────────────────────────────────────────────────┤
│                     数据层                            │
│        PostgreSQL    |    Redis    |    S3/OSS        │
├─────────────────────────────────────────────────────┤
│                   外部服务集成                         │
│   Stripe | 银行电汇确认 | 物流 API | 邮件服务          │
└─────────────────────────────────────────────────────┘
```

### 4.2 技术栈

| 层 | 技术 |
|----|------|
| 后端框架 | Medusa 2.0 (Node.js + TypeScript) |
| 前台框架 | Next.js 14+ (App Router) |
| 多语言 | next-intl |
| 数据库 | PostgreSQL |
| 缓存 | Redis |

| 管理后台 | Medusa Admin Dashboard（扩展） |
| 部署 | Docker + 云服务（TBD） |

## 5. 数据模型

### 5.1 产品模型（扩展 Medusa Product）

**Medusa 原生字段**（直接复用）：

| 字段 | 说明 |
|------|------|
| title | 产品名称（多语言） |
| description | 产品描述（多语言） |
| handle | URL 友好标识 |
| variants | SKU / 规格变体 |
| images | 产品图片 |
| categories | 产品分类 |
| tags | 标签 |
| metadata | 扩展元数据 JSON |

**自定义扩展字段**（玩具 B2B 特有）：

| 字段 | 说明 |
|------|------|
| age_range | 适用年龄（0-3 / 3-6 / 6-12 等） |
| certifications | 认证列表（CE / ASTM / EN71 等） |
| material | 材质（塑料 / 木质 / 毛绒等） |
| origin_region | 产地（汕头 / 义乌 / 深圳等） |
| min_order_qty | 最低起订量（MOQ） |
| is_in_stock | 现货 / 需预订 |
| sample_available | 可否寄样 |
| lead_time_days | 生产周期（天） |
| packaging_info | 包装尺寸 / 重量 / 装箱量 |
| factory_id | 关联工厂（外键） |

### 5.2 阶梯定价模型（自定义模块）

每个 Product Variant 可配置多层级价格：

```
Tier 1: MOQ - 99 件   → $5.00/件
Tier 2: 100 - 499 件  → $4.20/件
Tier 3: 500+ 件       → $3.50/件
```

### 5.3 工厂模型（自定义模块）

| 字段 | 说明 |
|------|------|
| name | 工厂名称（多语言） |
| description | 工厂简介（多语言） |
| location | 所在地（省/市/详细地址） |
| established_year | 成立年份 |
| employee_scale | 员工规模 |
| monthly_capacity | 月产能 |
| main_categories | 主营品类 |
| certifications | 认证资质（ISO / CE / ICTI 等） |
| photos | 工厂照片 / 视频 |
| status | 合作状态（启用/暂停） |
| slug | URL 友好标识 |

**数据关系**：Factory → 一对多 → Product

## 6. 核心用户流程

### 6.1 标准品直接采购

适用场景：现货玩具、低 MOQ、价格透明。

```
搜索/浏览商品 → 筛选 MOQ/认证 → 查看阶梯价 → 加入购物车
→ 选择支付方式 → 在线支付/电汇确认 → 订单确认发货
```

### 6.2 定制品询价（RFQ）

适用场景：OEM/ODM 定制、打样、大批量采购。

```
浏览产品/工厂 → 提交 RFQ 询价单 → 平台回复报价
→ 多轮沟通协商 → 确认报价单 → 转为正式订单 → 支付 + 生产 + 发货
```

### 6.3 支付方式

| 方式 | 适用买家 | 流程 |
|------|---------|------|
| 信用卡 / PayPal（Stripe） | 小B 买家（跨境卖家、KOL） | 在线即时支付 |
| 银行电汇（T/T） | 中B 买家（批发商、品牌商） | 线下汇款 → 上传凭证 → 平台确认到账 |

## 10. 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 架构方案 | Medusa 深度定制 | 开发速度最快，核心电商逻辑开箱即用 |
| 定价模式 | 混合（阶梯价 + RFQ） | 标准品直接交易，定制品走询价 |
| 多语言实现 | next-intl + Medusa i18n | Next.js 生态成熟，支持 RTL |
| 支付 | Stripe + 电汇 | 覆盖小B便捷支付 + 中B传统支付 |
| 工厂模式 | 平台自营 + 前台展示 | 简化运营，同时保留工厂背书能力 |
| 自定义模块 | Factory / RFQ / Tiered Pricing / Buyer Tier / MOQ Tag | 通过 Medusa Module SDK 扩展 |
